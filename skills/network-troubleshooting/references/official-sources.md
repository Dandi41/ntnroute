cite a forum without checking it against official documentation. Use
`web_search` and `web_extract`.

## Search tips

- Add `site:<domain>` to restrict results to official domains.
- For a specific error, search: `<brand> <error-message> troubleshooting`.
- For an unknown command, search: `<brand> <command> command reference`.
- If the official community yields nothing, try: `<brand> <symptom> site:reddit.com`.
- Always verify the OS version — commands can differ between major releases.
